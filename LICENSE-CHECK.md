# LICENSE-CHECK — CI License Compliance Gate

**Project:** nova-obs-fork (StreamFX OBS plugin)
**Governing License:** GNU General Public License v3 (or later) — SPDX `GPL-3.0-or-later`
**Status:** Active CI gate (blocking)

This file is the **blocking CI license-compliance gate** for the `nova-obs-fork` repository.
It is consumed by the `license-check` job in `.github/workflows/validate.yml` and by
all downstream Nexus ecosystem consumers.

## 1. Governing License

| Field | Value |
|-------|-------|
| Root `LICENSE` file | GNU GPL v3 (29 June 2007) |
| SPDX identifier | `GPL-3.0-or-later` |
| Commercial derivative | BLOCKED — see §4 |

The root `LICENSE` file **must** contain the official FSF GPLv3 text. Any PR that
changes the root license text without an approved Nexus governance decision
automatically fails this gate.

### 2.1 Prohibited Licenses

The following license families **automatically fail** the `license-check` gate:

- **GPLv2-only** (without the "or later" clause) — incompatible with GPLv3 strong copyleft.
- **Apache-2.0** with patent-retaliation clauses — patent grant conflicts with GPLv3 s11.
- **BSD-2-Clause** (when used in kernel-space / render-path code) — see R-LIC-02.
- **Proprietary / commercial** licenses in source-tree vendored code.
- **AGPL-3.0-only** — creates a derivative copyleft escalation beyond GPLv3.

### 2.2 SPDX Header Requirement

All source files (`.cpp`, `.hpp`, `.cc`, `.h`, `.cu`, `.cl`, `.glsl`, `.vert`, `.frag`)
added or modified in a PR **must** carry a copyright header with an SPDX identifier.

**Template:**

```
// AUTOGENERATED COPYRIGHT HEADER START
// Copyright (C) <year> <author> <email>
// SPDX-License-Identifier: GPL-3.0-or-later
// AUTOGENERATED COPYRIGHT HEADER END
```

The `copyright.js` tool (run in the existing `validate` job) enforces header
presence. The `license-check` job enforces SPDX identifier correctness.

## 3. CI Enforcement

The `license-check` job in `.github/workflows/validate.yml`:

1. **Checks** that the root `LICENSE` file contains the FSF GPLv3 text.
2. **Runs** `tools/rt_safety_audit.py` for the RT-safety gate (R-TECH-01).
3. **Scans** all new/modified source files for SPDX header compliance.
4. **Verifies** no prohibited license dependencies are introduced.

The job is **`allow_failure: false`** — a failure blocks the PR from merging.

## 4. Commercial Derivative Policy (R-LIC-01)

> **BLOCKED.** GPLv3 strong copyleft prohibits incorporating this code into the
> proprietary Nexus commercial tree without releasing the derivative source.

This repository is treated as an **open-source deliverable only**. Do NOT merge
its source into any closed-source Nexus commercial product. See
`docs/LICENSE_AUDIT.md` §Commercial-Derivative Flag for the full analysis and
clean-room alternatives (option (c)).
