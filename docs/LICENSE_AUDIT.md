## Summary

project as *"GPLv3 (or later)"*. This was a contradiction. Per directive, the governing
license is now **GPLv3 (or later)** and the `LICENSE` file has been replaced with the
official FSF GPLv3 text (29 June 2007).

## Commercial-Derivative Flag (Nexus Ecosystem)
GPLv3 is **strong copyleft**. Any binary分发 (distribution) of this plugin — or any work
that links/derives from it — must be released under GPLv3 with complete corresponding source.
This is incompatible with the Nexus proprietary commercial tree (closed-source). If Nexus
intends to ship a commercial product that incorporates StreamFX-derived code, it must either:
- (a) keep that product GPLv3 and open-source its derivative, or
- (b) obtain a separate proprietary license from the upstream rights holders (not available
  from Xaymar for StreamFX under current terms), or
- (c) clean-room reimplement the desired effects without deriving from GPLv3 code.

**Recommendation:** treat `obs-fork` as an open-source OBS plugin deliverable only; do not
merge its source into the proprietary Nexus commercial codebase.
